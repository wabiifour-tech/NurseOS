## SCREEN RECORDING GUIDE

### Equipment needed:
- **Desktop:** Use OBS Studio (free) or Loom
- **Mobile:** Use built-in screen recorder (Android: pull down shade → Screen Record; iOS: Control Center → Screen Recording)
- **Resolution:** 1920x1080 (desktop), 1080x1920 vertical (mobile)
- **Frame rate:** 30fps minimum

### Recording settings:
- **Browser:** Chrome (clean profile, no extensions visible)
- **Zoom:** 100% (don't zoom in — record at native resolution)
- **Cursor:** Make it visible, move slowly and deliberately
- **No audio during recording** — add voiceover later

### What to record (in order):

#### 1. HOMEPAGE (10 seconds)
- Open https://www.nurseos.digital
- Let it load fully
- Slow scroll through: hero → who is it for → what's inside → academic → download section
- Scroll back to top

#### 2. REGISTRATION (5 seconds)
- Click "Get Started"
- Show the Google sign-in button (don't actually sign in)

#### 3. LECTURER DASHBOARD (15 seconds)
- Log in as lecturer (test-login)
- Show the clean dashboard with only academic features
- Click "Upload Material" → show the upload dialog
- Show the materials list with analytics + share + Q&A buttons

#### 4. STUDENT DASHBOARD (15 seconds)
- Log in as student
- Show course materials list
- Click "View Material" → show the split-screen viewer with Q&A panel
- Type a question in the Q&A

#### 5. INSTITUTION ADMIN DASHBOARD (15 seconds)
- Log in as institution admin
- Show the clean dashboard: lecturers list, students list with matric numbers, students by level
- Show the "Free Forever" subscription card
- Show pending lecturer approvals (if any)

#### 6. ANNOUNCEMENTS (10 seconds)
- Show announcements page
- Create a new announcement targeting "200 Level"

#### 7. MOBILE EXPERIENCE (10 seconds)
- Record on phone (vertical)
- Show the PWA installed on home screen
- Open it → show dashboard → course materials → open a material

### Editing tips:
- **Transitions:** Use simple cross-dissolves (0.3s). No fancy effects.
- **Text overlays:** Use clean sans-serif font (Inter, SF Pro, or similar). White text on dark background.
- **Pacing:** Slow enough to read, fast enough to stay engaging. 2-3 seconds per screen.
- **Color:** Keep the slate/white/emerald palette consistent with the website.
- **Export:** 1080p, H.264, 30fps, MP4 format
